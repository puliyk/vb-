## 什么是 Vibe Coding

Vibe Coding 是一种 AI 辅助开发工作流：开发者通过自然语言描述需求（提示词），AI 生成代码，开发者审查、测试、反馈，形成迭代闭环。本日志记录了开发过程中每一轮关键提示词及其产出成果。

**AI 产出**：

- 支持 Python：def / if（含 if 数字的特殊解释）/ for（含 range 解析）/ print / return / 变量赋值

- 技术版新增"代码说明"section（在函数签名和参数列表之间）

**关键决策**：语句解释与函数级分析互补——函数级回答"这是什么"，语句级回答"它实际做了什么"。

## Vibe Coding 工作流心得

1. **渐进式迭代**：每个提示词聚焦一个维度（结构/解析/叙事/视觉），而非一次性要求全部功能。
2. **文档驱动**：PRD、TECH_DESIGN、全局约束等文档作为"锚点"，确保 AI 每一步都有明确的对齐目标。
3. **反馈闭环**：每轮产出后立即测试验证，发现问题进入下一轮修正。
4. **单文件策略**：初期模块化便于理解，后期合并为单文件降低 AI 跨文件编辑的出错率。
5. **约束文档的价值**：全局.md 和 样式修改.md 作为"宪法级"约束，在每轮都被引用，保证 AI 不偏离设计方向。
