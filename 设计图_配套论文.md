## 图3：比喻匹配加权评分算法流程图

```
                        输入: code, parsed, patterns
                                   │
                                   ▼
                    ┌──────────────────────────┐
                    │  初始化 bestScore = 0     │
                    │        bestEntry = null   │
                    └──────────────┬───────────┘
                                   │
                    ┌──────────────▼───────────┐
                    │  for each entry in       │
                    │  METAPHOR_LIBRARY (38条) │
                    └──────────────┬───────────┘
                                   │
                    ┌──────────────▼───────────┐
                    │  Step 1: 函数名匹配       │
                    │  关键词 ∈ 函数名? → +8分  │
                    │  概念词 ∈ 函数名? → +6分  │
                    └──────────────┬───────────┘
                                   │
                    ┌──────────────▼───────────┐
                    │  Step 2: 代码体匹配       │
                    │  关键词 ∈ 代码体?        │
                    │  泛型词(if/for/return)    │
                    │    → +1分                 │
                    │  领域词(sort/cache/api)   │
                    │    → +3分                 │
                    └──────────────┬───────────┘
                                   │
                    ┌──────────────▼───────────┐
                    │  Step 3: 模式交叉验证     │
                    │  概念词 ∩ 检测模式?       │
                    │    → +7分                 │
                    └──────────────┬───────────┘
                                   │
                    ┌──────────────▼───────────┐
                    │  score > bestScore?       │
                    │  YES → 更新 best          │
                    │  NO  → 继续下一条         │
                    └──────────────┬───────────┘
                                   │
                    ┌──────────────▼───────────┐
                    │  判定匹配质量:             │
                    │  score ≥ 8  → "strong"   │
                    │  score ≥ 1  → "moderate" │
                    │  score = 0  → "fallback" │
                    └──────────────┬───────────┘
                                   │
                                   ▼
                        输出: { entry, matchQuality,
                               firstKeyword, inferReason }
```
